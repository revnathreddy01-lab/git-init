# Employee Registration

A small, responsive employee registration page built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a modern browser. No build step or dependencies are required.

## Features

- Captures employee name, email, department, job title, start date, and optional phone number.
- Validates required fields and prevents duplicate email addresses.
- Displays and removes employees in a directory.
- Saves records in the browser's local storage.

> This is a front-end demo. Employee information stays in the current browser and is not sent to a server. Do not use it as a production employee system without adding secure server-side storage, authentication, and access controls.
