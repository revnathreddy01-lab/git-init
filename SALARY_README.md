# Salary Calculator

A responsive salary calculation page that estimates per-period gross pay, tax deductions, and net pay.

## Run

Open `salary.html` in a modern browser.

## Formula

- Gross pay per period = annual base salary / pay periods per year
- Tax deduction = gross pay × tax rate
- Net pay = gross pay − tax deduction − other deductions

This is an estimation tool only. It does not calculate jurisdiction-specific taxes or withholdings.
